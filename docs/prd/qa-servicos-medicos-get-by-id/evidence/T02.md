# T02 — Não encontrado (UUID sintaticamente válido, inexistente na tabela)

## Comando executado

```
curl -s -i -X GET "http://localhost:8080/v1/api/servicos-medicos/00000000-0000-0000-0000-000000000000" \
  -H "Authorization: Bearer eyJhbGciOiJIUzUxMiJ9...[REDIGIDO]" \
  -H "Accept: application/json"
```

## Resposta crua

```
HTTP/1.1 404
X-Content-Type-Options: nosniff
X-XSS-Protection: 0
Cache-Control: no-cache, no-store, max-age=0, must-revalidate
Pragma: no-cache
Expires: 0
X-Frame-Options: DENY
Content-Type: application/problem+json
Transfer-Encoding: chunked
Date: Sat, 15 Aug 2026 15:15:32 GMT

{"detail":"Serviço médico não encontrado: 00000000-0000-0000-0000-000000000000","instance":"/v1/api/servicos-medicos/00000000-0000-0000-0000-000000000000","status":404,"title":"Recurso não encontrado","type":"https://sgsm.com.br/erros/recurso-nao-encontrado"}
```

## Avaliação

- Status: `404` — conforme esperado.
- `Content-Type: application/problem+json` — confirma que o formato real de erro é
  **RFC 7807 `ProblemDetail`** (`type`, `title`, `status`, `detail`, `instance`), **não**
  o formato documentado no README (`{"timestamp","status","erro"}`). Achado a reportar:
  README desatualizado em relação ao contrato de erro real.

**RESULTADO: APROVADO** (comportamento funcional correto; nota sobre divergência de documentação registrada, não é falha do endpoint)
