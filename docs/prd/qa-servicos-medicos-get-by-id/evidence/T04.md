# T04 — GET sem header Authorization

## Comando executado

```
curl -s -i -X GET "http://localhost:8080/v1/api/servicos-medicos/241760a1-efdc-44c6-b3c2-1f3a64013fe4" \
  -H "Accept: application/json"
```

## Resposta crua

```
HTTP/1.1 403
X-Content-Type-Options: nosniff
X-XSS-Protection: 0
Cache-Control: no-cache, no-store, max-age=0, must-revalidate
Pragma: no-cache
Expires: 0
X-Frame-Options: DENY
Content-Length: 0
Date: Sat, 15 Aug 2026 15:16:34 GMT

(corpo vazio)
```

## Avaliação

- Status real observado: **`403 Forbidden`** (não `401`), corpo vazio (`Content-Length: 0`).
  Confirma que a app não tem `AuthenticationEntryPoint` customizado — Spring Security
  aplica o comportamento padrão para `anyRequest().authenticated()` sem contexto de
  autenticação, que neste projeto resulta em 403.

**RESULTADO: APROVADO** (registra o status real, conforme pedido pelo plano — não havia expectativa fixa de 401 vs 403)
