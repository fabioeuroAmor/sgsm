### Comando

```

  -H "Authorization: Bearer eyJhbGciOiJIUzUxMiJ9...[REDIGIDO]" \
  -H "Content-Type: application/json" \
  -d '{"medicoId":"ff9a2400-2217-48fa-ac91-b81a4032f2db","nome":"QA Descartavel","descricao":"registro de teste, pode ser removido","preco":50.00,"duracaoMinutos":15,"domiciliar":false,"taxaDeslocamento":null}'
```

## Avaliação

- POST cria registro `201`, `ativo:true`.
- GET antes do delete: `200`, `ativo:true` — consistente com DB (`ativo = t`).
- DELETE: `204 No Content`.
- GET depois do delete: **`200`** (não `404`, não `410`), corpo com `ativo:false` —
  confirma soft-delete. DB mostra a linha ainda presente com `ativo = f` (não houve
  `DELETE FROM`, apenas `UPDATE`).
